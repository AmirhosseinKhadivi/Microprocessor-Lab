# Microprocessor Lab

A collection of projects and assignments completed for the **Microprocessor Laboratory** course.

## Overview

This repository contains AVR-based microprocessor laboratory projects implemented using **C**, **CodeVisionAVR**, **CodeWizardAVR**, and **Proteus**.
